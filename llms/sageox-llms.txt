# SageOx

> The hivemind for human-agent teams. SageOx captures team discussions, decisions, and AI coding-agent work sessions into a searchable Ledger (per-repo history) and Team Context (team-wide knowledge), so agents inherit full context instead of starting cold. Integrate via the Ox CLI, the hosted Ox MCP server, and a REST API. Seattle-based; $15M seed (May 2026) led by Canaan Partners.

## APIs

- [SageOx REST API (OpenAPI 3.1)](https://sageox.ai/openapi.json): 223 operations across repositories, recordings, teams, users, notifications, runs, API keys, devices (Ox Dot), and an OpenAI-compatible LLM proxy. JWT bearer auth.
- [Ox MCP server](https://sageox.ai/api/v1/mcp): hosted Model Context Protocol endpoint with OAuth-scoped grants; query team memberships, search team knowledge, and save sessions to Knowledge Bubbles.
